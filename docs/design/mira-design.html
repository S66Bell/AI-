この文書の読み方

最初の 3 章だけ読めば、仕組みの全体がつかめます。4 章以降は「中で何が起きているか」「なぜ安全か」「どう運用するか」を順に説明します。コマンドは Mac のターミナルで実行するものです。

1. この仕組みを一言でいうと

自宅の Mac の中で動く「自分専用の AI(MIRA)」に、スマホからどこでも、暗号化された専用回線でつなぐ仕組み。
会話の内容は Mac の外に出ず、料金もかからない。MIRA は話すだけでなく、検索・ファイル操作・定期的な作業をこなし、会話からあなたのことを覚えていく。
頭脳は Mac の中オープンな言語モデル(Qwen2.5-14B)を Mac の GPU で動かす。クラウドの AI サービスは使わない(使いたい場合だけ切り替え可)。
入口はスマホのブラウザアプリをインストールする必要はなく、Chrome でページを開くだけ。ホーム画面に追加すれば普通のアプリのように使える。音声入力も可。
つなぐのは Tailscale自分のアカウントでログインした端末同士だけをつなぐ暗号化ネットワーク。ポート開放なし、第三者は到達すらできない。
守りは多層ネットワーク制限、トークン認証、ファイル操作の範囲制限、危険操作の事前確認、Web ページからの「なりすまし指示」対策など。

2. 全体像(概念図)

図 1: 全体像。スマホは「画面」、Mac が「頭脳・記憶・手」。間を Tailscale の暗号化トンネルがつなぐ。

ポイントは 3 つです。① 会話も記憶もモデルも Mac の中で完結する。② スマホからは HTTPS の URL を開くだけで、Mac 側には「あなたの Tailscale アカウントの端末」しか届かない。③ MIRA が外へ出るのは Web 検索・取得だけで、それも安全確認付き。

3. MIRA にできること

機能内容使う場所
会話親友のようなフランクな日本語で話す。結論を先に、短く。必要ならツールを使って実際に調べる・やる。チャットタブ
バックグラウンドタスク「今週の AI ニュースを 3 つ調べて要約して」のような目標を渡すと、計画→ツール実行→自己チェック→報告まで一人で進める。進捗はリアルタイム、中止も可。タスクタブ(チャットから「調べておいて」でも可)
定期実行毎日 8:00、60 分ごと、などの予定でタスクを自動実行。Mac が寝ていた分は起動後に 1 回だけ実行。定期実行タブ
記憶「覚えておいて」と言われたこと、会話から読み取れる事実(名前、好み、予定、人間関係)を長期記憶に保存。古い会話は要約して保持。記憶タブ(自動 + 手動)
音声マイクボタンで音声入力、設定で返事の読み上げ。HTTPS 配信なのでスマホでも動く。チャットタブ
Web 検索・ページ取得DuckDuckGo で検索し、ページ本文を読んで答える。鍵不要・無料。自動(MIRA が判断)
ファイル・シェル作業用フォルダ内でファイルを読み書き、コマンドを実行。危険な操作は実行前に画面で確認。自動(確認ダイアログ)

画面の構成

チャット光る球体が状態表示(待機=ゆっくり、処理中=速く、エラー=赤)。「考え中… N秒」で待ち時間が分かる。■で中断。
タスク目標を入力して「バックグラウンドで実行」。各タスクの状態(queued / running / done / failed)、報告、実行ログ。
定期実行目標と「毎日 HH:MM」または「N 分ごと」を登録。今すぐ実行・停止・削除。
記憶会話の要約と覚えている事実の一覧。「今の会話から学習」「履歴を全部消す」「この端末のトークンを消す」。

4. 構成要素の説明

要素役割実体
スマホのブラウザ(PWA)画面。入力を送り、返事をストリーミング表示。トークンを端末内に記憶。jarvis/web/static/index.html
Tailscale(スマホ・Mac)自分のアカウントの端末だけをつなぐ暗号化ネットワーク。Mac 側の Serve 機能が HTTPS で MIRA を公開(tailnet 内のみ)。Tailscale アプリ / scripts/mac/tailscale.sh
MIRA Web サーバー認証、画面配信、API。会話を 1 つずつ処理し、ツールの確認を画面に出す。タスク・予定・学習の司令塔。jarvis/web/server.py
アシスタント(人格・進行)MIRA の人格(システムプロンプト)と記憶を組み合わせ、モデルとツールの往復(エージェントループ)を進める。jarvis/assistant.py, persona.py
バックエンド(頭脳への接続)どのモデルサーバーと話すか。llama.cpp / Groq / Ollama / Claude を同じ作法で扱う。小さなモデルが崩したツール呼び出しも修復。jarvis/backends/
モデルサーバー言語モデル本体を GPU で動かし、文章を生成する。Mac の中だけ(127.0.0.1)で待ち受け。llama-server(Homebrew) + GGUF ファイル
ツール群MIRA の「手」。Web 検索・取得、ファイル、シェル、記憶、時刻など。安全確認付き。jarvis/tools/
記憶・学習会話履歴、長期記憶、要約。数往復ごとに会話から事実を抽出して記憶へ。jarvis/memory.py, learning.py
タスク実行・スケジューラバックグラウンドタスクを 1 つずつ実行。予定表に従って自動起動。jarvis/agent.py, scheduler.py
設定名前、呼び名、頭脳の種類、トークン、セキュリティの各設定。.env

※ 設定項目の名前が JARVIS_ で始まるのは、プロジェクト初期の名前の名残です。アシスタントの名前は JARVIS_NAME(= MIRA)で決まります。

5. 会話が処理される流れ

図 2: 1 回の会話の流れ。モデルは「考える」、ツールは「やる」、サーバーがその間を取り持つ。

速さを決めるもの

返事の時間は「プロンプトの読み込み」と「文章の生成」の合計です。人格・ツール一覧・記憶で約 2,000 トークンあるため、前回の内容をキャッシュして差分だけ読む設計にしています(時刻を分単位で入れない、学習処理は会話中に走らせない、モデルサーバーは 1 スロット)。Mac(Metal)の 14B なら、初回 5〜10 秒、以降は数秒が目安です。

6. 記憶と学習の仕組み(自己学習)

モデル自体を学習し直す(重みを更新する)のは個人の Mac では現実的でないため、MIRA は「記憶」で学習します。会話から事実を抽出して蓄積し、毎回の会話の冒頭でそれを読み直す方式です。
図 3: 会話 → 振り返り → 長期記憶 → 次回のプロンプト、という循環。

自己学習の 3 つのループ

何を学ぶかきっかけMIRA がすること次に活きる場面
接し方(lessons)返事への 👎、「違う」「もっと短く」などの訂正、6 往復ごとの振り返り「〜のときは〜する」という 1 文のルールを自分で作って保存(重複は捨てる、最大 40 件)毎回の人格に「必ず守る接し方」として追加
知識(knowledge)「このページを覚えて」「この文章を覚えて」、記憶タブの入力欄、ワークスペース内のファイル本文を 600 字程度に分けて索引化(日本語対応の軽量全文検索)。追加モデル不要質問に関係する部分を自動で引いて返事の材料にする。search_knowledge でも検索
やり方(playbook)バックグラウンドタスクの完了・失敗目標・ログ・結果から「次に似た作業をするときの教訓」を 1〜2 文で書き残す似た目標のタスクを始めるとき、教訓を先に読む

いずれも Mac の中で完結し、人格・記憶タブからいつでも見直し・削除できます。モデルの重み自体は変えないので、学習で賢さが壊れることはありません。

保存されるもの場所消し方
会話履歴(本文)~/.jarvis/conversation.jsonl記憶タブ「履歴を全部消す」
学んだ接し方~/.jarvis/lessons.json記憶タブで個別に「消す」
覚えさせた知識~/.jarvis/knowledge.json記憶タブで個別に「消す」
作業の教訓~/.jarvis/playbook.jsonファイルを削除
覚えている事実~/.jarvis/memory.json記憶タブで個別に「忘れる」

7. エージェント(バックグラウンドタスクと定期実行)

図 4: タスクは「計画 → 実行 → 自己チェック → 報告」。1 つずつ順番に処理される。

定期実行

  • 「毎日 HH:MM」または「N 分ごと」で登録。20 秒ごとに予定表を確認し、時刻が来たらタスクとして実行。
  • Mac がスリープしていて実行できなかった分は、起動後に 1 回だけまとめて実行(何回も走らない)。
  • 結果は「タスク」タブに残り、チャットにも「バックグラウンドタスク完了」として通知。

チャットからの委任

「〜を調べておいて」と頼むと、MIRA 自身が start_background_task ツールでタスクを作り、会話を止めずに裏で進めます。進捗は「〜どうなった?」と聞けば答えます。

8. セキュリティ設計

図 5: 4 層の守り。外側から順に「届かない → 使えない → 壊せない → 騙されない」。
想定する脅威対策
第三者がインターネットから接続Tailscale 内でしか到達できない。万一ポート開放しても許可ネットワーク外は 403。
同じ Wi-Fi の機器からの接続Web UI は 127.0.0.1 のみ待ち受け(LAN から直接は届かない)。
トークンの総当たり96 ビットの乱数 + 10 回失敗で 10 分ロック。
悪意あるサイト経由の操作(CSRF)Cookie 認証なし、JSON 以外の POST 拒否、CSP。
Web ページに仕込まれた「MIRA への指示」信用できないデータと明記し、そのターンの副作用は確認制。裏作業は自動拒否。
AI が誤って重要ファイルを壊す作業フォルダ外は読めない・書けない。危険コマンドは事前確認。
AI にルーターや内部サービスを触らせるweb_fetch はローカル/プライベートアドレスを拒否。
設定ファイル・ログからの漏えい.env は 600、~/.jarvis は 700、ログに会話本文を残さない。

残るリスク: トークンを知る人は MIRA を操作できる(人に見せない・漏れたら作り直す)。確認ダイアログは内容を読んでから押す。Groq など外部の頭脳を使うときは会話が外に出る。詳細は docs/SECURITY.md。

9. 頭脳(モデル)の選択肢

MIRA の人格・記憶・ツール・画面はそのままに、頭脳だけを切り替えられます。切り替えは bash scripts/brain.sh … と再起動だけです。

11. 運用手順

毎日の使い方

  • Mac: ログインしていれば自動で動いている(常駐サービスを入れた場合)。入れていなければ bash scripts/mac/start.sh。
  • スマホ: Tailscale をオンにして、ホーム画面の MIRA を開く。
  • Mac がスリープすると届かない。ノートは電源につなぎ、電源接続時のスリープを防ぐ設定にする。

よく使うコマンド

cd ~/mira
bash scripts/mac/start.sh              # 起動(Ctrl-C で停止)
bash scripts/mac/stop.sh               # 停止(常駐サービスも止める)
bash scripts/mac/install-service.sh    # ログイン時に自動起動(remove で解除)
git pull                               # 最新版に更新(そのあと再起動)
bash scripts/brain.sh groq gsk_キー     # 頭脳を Groq に
bash scripts/brain.sh local            # 頭脳を Mac に戻す
bash scripts/mac/tailscale.sh off      # Tailscale 配信をやめて LAN に戻す

トークンを作り直す

sed -i '' "s|^JARVIS_WEB_TOKEN=.*|JARVIS_WEB_TOKEN=$(.venv/bin/python -c 'import secrets;print(secrets.token_hex(12))')|" .env
grep JARVIS_WEB_TOKEN .env             # 新しいトークンを確認 → 再起動 → スマホで再入力

困ったとき

症状確認・対処
スマホで「このサイトにアクセスできません」Mac で MIRA が動いているか(start.sh の画面)。スマホの Tailscale がオンか。Mac がスリープしていないか。
トークンを聞かれ続ける.env の JARVIS_WEB_TOKEN を確認。10 回間違えると 10 分ロック。
返事が遅いgrep -E "prompt eval time|eval time" ~/.jarvis/llama-server.log | tail -n 4 で速度を確認。他の重いアプリを閉じる。7B に変える。
起動時に llama-server exitedtail -n 30 ~/.jarvis/llama-server.log。メモリ不足なら小さいモデルへ。
中国語や英語で返してくる人格の指示で日本語を指定済み。続くなら「日本語で」と一言。14B ではほぼ起きない。
常駐サービスのログを見たいtail -f ~/.jarvis/mac.log、会話処理の記録は ~/.jarvis/web.log。

12. 用語集

用語意味
言語モデル(LLM)文章を読んで続きを生成する AI の本体。MIRA の「頭脳」。
GGUF / 量子化モデルを小さく圧縮した形式。4bit 量子化で品質をほぼ保ったままサイズを 1/4 に。
llama.cpp / llama-serverGGUF モデルを Mac などで高速に動かすソフト。Metal(Apple の GPU 機能)を使う。
トークンモデルが扱う文字のかたまり。日本語は 1〜2 文字で 1 トークン程度。「トークン/秒」が速さの単位。
プロンプト / システムプロンプトモデルに渡す文章。冒頭の「人格・記憶・ルール」部分がシステムプロンプト。
ツール呼び出しモデルが「検索して」「このファイルを読んで」と要求し、サーバーが実行して結果を返す仕組み。
エージェント目標に向けてツールを何度も使い、自分で進める AI の使い方。
PWAブラウザのページをアプリのようにホーム画面に置ける仕組み。HTTPS が必要。
Tailscale / tailnet自分の端末同士だけをつなぐ暗号化ネットワーク(VPN の一種)。その自分専用ネットワークが tailnet。
Tailscale Servetailnet 内の端末に対して、Mac 上のサービスを HTTPS で公開する機能。
アクセストークンMIRA を使うための合言葉。ブラウザが記憶し、毎回ヘッダーで送る。
プロンプトインジェクションWeb ページなどに「AI への偽の指示」を仕込み、AI を操ろうとする攻撃。
SSRFサーバー(ここでは MIRA)に、内部ネットワークへアクセスさせる攻撃。
CSP / CSRFブラウザ側の防御設定 / 他サイト経由で操作させる攻撃。MIRA は両方に対策済み。
KV キャッシュモデルが一度読んだプロンプトの計算結果。使い回すと 2 回目以降が速くなる。
